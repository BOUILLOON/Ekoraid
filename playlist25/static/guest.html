Les fichiers pour le jour J.

Ce site gratuit collecte les idées et les votes, même quand votre PC est éteint. Pour récupérer l’audio et préparer le pack, utilisez l’application sur le PC de l’organisation.

  1. Installer et lancer l’application sur le PCLe guide explique le lancement du studio privé. Lorsqu’une version ZIP du studio est publiée, décompressez-la sur ce PC puis double-cliquez sur son lanceur.
  2. Récupérer les propositions du site publicDans le studio : Réglages → Récupérer les propositions du site public.
  3. Choisir et télécharger la sélectionDans Propositions, validez les idées puis choisissez « Tout sélectionner » ou « Sélectionner tous les validés ». Cliquez sur « Préparer les fichiers de la sélection », confirmez les autorisations et suivez la progression dans Téléchargements.
  4. Récupérer les fichiers prêtsLes fichiers contrôlés sont dans la Bibliothèque locale. Depuis Téléchargements, choisissez « Récupérer les fichiers prêts en ZIP », ou depuis Bibliothèque locale, « Récupérer mes fichiers en ZIP ». Créez le ZIP, puis cliquez sur « Télécharger le ZIP sur cet appareil ». Pour un téléphone, préparez le ZIP sur le PC puis cliquez sur « Partager sur mon Wi-Fi ». Affichez le QR code et scannez-le avec le téléphone, connecté au même Wi-Fi que le PC. Ce lien permet de récupérer ce ZIP pendant 10 minutes ; « Fermer le partage » le désactive.
Télécharger la version ZIP du studio →Lire le guide de l’organisation →Ouvrir le studio sur ce PC →

Le bouton du studio ouvre ce PC, pas un serveur distant. Il fonctionne après le lancement de l’application locale. Le site public ne télécharge pas l’audio. Le partage d’un ZIP par QR code reste distinct du studio privé : l’administration ne doit jamais être exposée au public.
